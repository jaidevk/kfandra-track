# KLC League — KFANDRA checkpoint

Run on the live app after the heads-up to KFANDRA. Tick each line.

- [ ] Replay 3–4 S1 matches from the KLCFERRSXVSG1 sheet: results, W/D/L and for/against match the sheet; points follow the new S2 scale (S1 used older rules). *(Needs Coach's sheet; bead "S1 acceptance replay".)*
- [ ] A 7+ football win gives 5 / 0; a 4–6 rugby variation win gives 1 / 0; a 4–6 football draw gives 0.2 / 0.2.
- [ ] Before Submit, the recorder's "League points" line shows the tier, score and each club's points (e.g. `Tier 2–3 · 2 – 1 · Kraken Leviathans 0.5 · Ninja Ballers 0`). A combined match shows the club pairs instead (e.g. `Kraken + Ninja 3 – 2 Rhinos + Dodos · 5 each · 0 each`).
- [ ] A joint-manager (combined) match gives each club on the winning pair 5 and appears once per club in P.
- [ ] A club manager records and submits their own club's match from Home → Record a match.
- [ ] A plain player opens Home → KLC League and sees Table, Matches, Leaders, Seasons and Scoring, and no drafts.
- [ ] KFANDRA reopens a match, edits the score and resubmits: the table changes.
- [ ] Scoring tab matches the agreed points scale.

Note: a league match counts for the season active when it is submitted, so reopening and resubmitting a match during a later season moves it into that season.
